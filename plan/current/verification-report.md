## Out-of-scope findings

1. **A setup rerun deletes a retired skill folder outside the project.** `cleanup_retired_tracks` refuses to remove `.claude/skills/ravintio-change-agent` when `.claude/skills` links outside the project. The manifest write then lists every folder in the skills folder, the refused one included. On the next run, the manifest prune deletes it through the link. Bash and PowerShell 7 both printed `  - removed: ravintio-change-agent`, and the outside folder was gone. Repro: `scripts/link-case.sh <scratch> sh shfirst` and `... ps1 shfirst`. Backlog 0000255's suggested fix compares the parent with the real skills folder, so it wouldn't stop this case.
2. **`pre-push` and the CI step print a false warning.** For a `product.yml` with no `path:` lines, such as `components: []`, the here-string loop reads one empty line. Both then print "product.yml at HEAD has an empty path: value. The rule ignores it." The verdict is still correct.
3. **No `v0.37.2` tag exists.** `git tag` ends at `v0.37.1`, while `main` carries 0.37.2.
